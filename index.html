Flutter Practical Programs

Simple Flutter projects for practical exam. Download the zip, extract it and run.

1. Login Page

Login screen with email and password. Checks empty fields, valid email and minimum 6 character password. After login it opens a home page with logout button.

Form, TextFormField, validator, Navigator

2. Calculator

3. To-Do List

Add tasks, mark them as completed using checkbox and delete them.

TextField, ListView.builder, Checkbox, Card

Download ZIP

4. BMI Calculator

Enter height in cm and weight in kg to calculate BMI and show category (Underweight, Normal, Overweight, Obese).

TextField, double.tryParse, SnackBar

Download ZIP

How to run

  1. Download and extract the zip file
  2. Open the folder in VS Code or Android Studio
  3. Run flutter pub get in terminal
  4. Start emulator or connect phone
  5. Run flutter run

All the code is in lib/main.dart.
